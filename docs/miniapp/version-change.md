# v1.1.0 版本变更单

## 变更类型
已上线项目的 UI 与性能重构（非新功能）

## 线上版本
v1.0.1（git tag 已存在）

## 开发中版本
v1.1.0

## 变更动机
用户要求：利用 WeUI 基础样式做 UI 美化，动画不卡顿。

## 范围

### 做
- 修 `.bar-fill` 的 `transition: width` 卡顿（改 `transform: scaleX`）
- 迁移 9 条进度条：dashboard 3 / healthhub 5 / settings 1
- 新增 WeUI 结构规范：`.cells` / `.cell` / 间距梯度 / `.tap` 按压态
- 新增 GPU 安全动效：`rise-in` / `num-pop` / `fade-slide`
- 版本号 1.0.1 → 1.1.0

### 不做（明确排除）
- 不引入 WeUI 组件包（会顶掉现有双主题 token，+100KB）
- 不启用 Skyline（渲染器变更风险高）
- 不改 11 个非 tabBar 页面
- 不改业务逻辑、存储、登录、分享
- 不改现有深色/浅色主题变量

## 受影响页面
dashboard / courses / tasks / healthhub / settings（5 个 tabBar 主页）
