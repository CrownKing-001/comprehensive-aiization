## UI 重构 v1.2.0（2026-10-30，未提交）

按四期推进。每期都跑完整校验，全部通过才进下一期。

### 第 1 期：图标系统（已完成）
- 根因：卡片头图标用彩色 emoji 放在定高盒子里，emoji 字形高度由系统字体决定、
  常超出盒子 → 压到标题上。**这就是「UI 重叠」的真正原因。**
- 改为 WeUI `mp-icon`（SVG），新增 `components/ui-icon/`（`icons.js` 是唯一语义来源）。
- 130 处 emoji → `<ui-icon>`；用户历史数据里的 emoji 用 `emojiToIcon()` 在渲染时转换，
  **不迁移、不销毁**（里程碑 emoji 是本机数据，无后端）。
- `.ui-icon` 默认 `display:block`，跟在文字前必须 `inline="{{true}}"`，否则会换行。

### 第 2 期：字号五档（已完成）
- 对齐微信官方 22/17/15/14/12 pt = 44/34/30/28/24 rpx。
- 308 处声明从 **24 种取值收敛到正好 5 档**。

### 第 3 期：去 AI 味（已完成）
| 项 | 之前 | 现在 | 原因 |
|---|---|---|---|
| 入场动画 | 上浮 16rpx + 逐条延迟 0.18s + 0.28s 时长 | 只做 0.18s 淡入，不移动 | 最长 0.46s 内内容不可读；也是「截图看起来重叠」的来源 |
| 欢迎条 | 绿色三色渐变 + 44rpx 彩色投影 | 单色实底 + 1rpx 描边 | 全站最花的一块 |
| 进度条 | 90° 双色渐变 | 单色 | 小尺寸下看不出渐变，反让两个进度条像同一套皮肤 |
| 圆角 | 11 档（6~28rpx） | 5 档（8/12/16/20/24 + 胶囊） | 相邻档差 0.5px，肉眼看不出却让每张卡都略不同 |
| 卡片描边 | 2rpx | 1rpx | 深色底上 2rpx 形成明显「贴纸描边」 |
| 卡片密度 | 24rpx 间距 / 26-30rpx 内边距 | 20rpx / 22-26rpx | 一屏装不满显得松散 |

### 第 4 期：对比度与双主题（已完成）
- `--text-4` 深色 3.47:1 → **5.24:1**（WCAG AA 要求 4.5:1）。
- 主按钮白字/绿底 3.77:1 → **5.48:1**（`#059669` → `#047857`，仅背景与边框）。
- 禁用态不再用 `opacity: 0.4`（浅色下仅 **1.83:1**），改用 `--disabled-*` token。
- **tabBar 不跟主题**：`app.json` 里是静态色，浅色主题下底部仍是深色带、深色图标压在上面看不见。
  新增 `utils/tabBarTheme.js`，在 `app.js` 启动、各 tab 页 `onShow`、`tabHost._syncTheme` 三处同步。

### 新增校验工具（都接进日常自检）
| 脚本 | 作用 |
|---|---|
| `tools/check-icons.js` | 语义名能否解析；**`{{...icon}}` 是否漏包 `<ui-icon>` 被当文字渲染** |
| `tools/check-selectors.js` | wxss 里的类名在 wxml 里是否真的存在（含 tabHost 子模块合并） |
| `tools/check-contrast.js` | 直接读 wxss 真实色值，**深浅两套主题**都算 WCAG 对比度 |
