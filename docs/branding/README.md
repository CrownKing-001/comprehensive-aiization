# 小程序头像

## 用哪个文件

| 用途 | 文件 |
| --- | --- |
| 微信公众平台「小程序头像」上传 | **`avatar-144.png`**（微信推荐尺寸，7.8 KB） |
| 需要更大尺寸时（如 App 图标、宣传物料） | `avatar-1024.png`（母版） |
| 预览两种裁切效果 | `avatar-preview.png` |

`avatar-512 / 256 / 96 / 48.png` 是按同一母版等比导出的备用尺寸。

## 设计约束

微信里同一个头像会同时以**圆形**和**方形**出现，所以：

1. **背景满幅出血**——四角不透明，方形裁切后不会出现空白角。
2. **图形全部落在内切圆内**——圆形裁切不会切到日历。
   实测图形最远点离中心 **396 px**，内切圆半径 512 px，余量 **22.7%**。
   这个数字由脚本自检，不靠肉眼：`make-avatar.py` 会逐像素对比
   「画了图形」和「只有背景」两张图得到图形掩膜，再算最远半径，
   越界直接 `assert` 失败。
3. 只有一种形状（日历）+ 一个符号（对勾），保证 40 px 下仍可辨认。

配色取自 App 自身：深色底 `#12203a → #080d15`，翠绿 `#3ddc97 → #059669`，
顶部色带 `#06926a → #04553d`。

## 重新生成

```powershell
& $py docs\branding\make-avatar.py
```

`$py` 指带 Pillow / numpy 的 Python。脚本把图形层放大 3 倍绘制再 LANCZOS
缩回，所以边缘没有锯齿。

## 修改时注意

- 图形层的坐标都写在 1024 空间，`k()` 负责乘到超采样空间，改尺寸时不用管倍率。
- 挂环坐标必须给**环心**（512±152）。写成「左边缘 + 半宽」会让两条环
  分别偏左 129、偏右 175，一眼就不平衡。
- 改完务必看脚本输出的余量百分比，低于 10% 就该缩小图形。
